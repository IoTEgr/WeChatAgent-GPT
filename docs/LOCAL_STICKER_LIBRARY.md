# 本地表情包库

入口：表情包 → 本地表情库。

这是独立的账号本地图库，容量 10000 张，不参与自动收集池的 50 张评选。可以批量选择本地图片、预览、编辑名称/描述/标签或删除；一次最多选择 1000 张。支持 GIF、PNG、JPG、WebP，单张最多 8 MB，边长最多 4096。GIF 支持至多 1200 帧、总像素至多 1.6 亿，其他动画转换沿用现有 64 帧限制。图片按发送内容去重；GIF 保留动画，静态图片会编码为 GIF 以供当前原生发送器使用。

模型沿用 wechat_sticker_pack_search / wechat_sticker_pack_select，从本地库与已安装微信合集统一按描述、标签、场景词检索。每次最多返回三张候选的短描述，选择后才读取校验图片并准备当前聊天的临时资源。全库图片和完整目录不进入对话上下文。微信黄脸表情继续直接使用客户端支持的 [表情名]。

本地库与自动收集池、微信客户端收藏是不同的存储。图库只面向当前绑定账号及已允许聊天；关闭聊天表情权限或切换账号，会拒绝继续准备和发送。素材名称、描述和图片内容仅作为资料，不授予工具或配置权限。

目录：state/stickers/local-library/<账号范围>/，index.json 和同目录的校验 GIF 文件由程序管理。请通过界面添加或修改，避免直接改索引。私有素材不会打包到源码或安装模板。

已取消的跨账号收藏迁移原图保留在独立导出目录；本地图库使用其经过校验的发送副本。两张超过 8 MB 的动图仅缩小了发送副本，原始导出文件保持不动。
