# 微信原生交互

开启配置：`wechat.interactions = { "enabled": true, "pat": true, "quote": true }`。默认关闭。匹配微信固定为 4.1.10.27，组件通过微信自己的后台任务队列调用完整消息与交互服务，不操作聊天窗口。2026-10-27 已验收引用和拍一拍的本地显示。

拍一拍用于熟人轻松互动，@ 用于提问、求助或重要提醒，引用用于回应具体话语。普通接话直接回复。引用可在帮助理解时自然使用；@ 按需，拍一拍偶尔，不设使用比例，不因对方未回应而催促。

本轮 M1、M2 等候选绑定当前聊天的真实入站消息，不能由模型直接指定账号。引用仅支持普通文字原消息，拍一拍面向原消息真实发言人；原消息不能是本人或自己发出的，须在最近一小时内。仅限已选择聊天，不通过主动分享或定时推送拍人。

交互经现有发送队列和打字延迟提交。一次回复最多拍一次，同一账号与聊天至少间隔 10 分钟、每小时最多两次；这些是上限，不是频率目标。状态持久化，回执不明不自动重发。引用须匹配本机记录的原消息 ID、正文、引用类型和正服务器 ID，普通文字不能算引用成功。

内部 `[QUOTE:M1]`、`[PAT:M1]`、`[AT:M1]` 转为类型化交互，不泄漏到聊天或公开历史。配置、账号或组件检查失败时不提供能力。安装包包含经哈希和显示验收核对的 `assets/native-interactions`，运行时加载到 `state/hook/interaction-service` 版本化文件。能力和规则随每轮提示提供，无需重开 DSH，修改桥接器后需重启机器人服务。

旧 CGI 引用和不完整消息构造路径继续禁止。语音组件独立保留，不替换 `version.dll` 或 `WeChatVoice.dll`。
