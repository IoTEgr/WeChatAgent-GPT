# 科技类主动分享

在“设置 → 聊天默认值 → 主动内容方向”可以选择“科技类分享”。在“聊天 → 设置此聊天”中，每个好友或群聊都可以独立选择内容方向，并填写公开关注主题，例如“AI、模型、开源工具”或“苹果、手机、芯片”。留空或选择继承时使用账号默认值。原有每聊天开关、安静时间、发送时段和间隔继续生效，助手模式不主动执行。

科技模式先读取 OpenAI、Google、Apple、NVIDIA、Microsoft 官方发布源，按发布日期保留最近 72 小时的内容，结合关注主题和本群历史筛选。只向模型提供最多 6 条有日期、出处的文字候选。话题可来自今天或近几天，文章发布时间不自动当成产品发布日；没有对应证据时不能编造性能提升、代际比较或排行。

正文通常是 2–4 个口语短句，围绕一件事说变化和感想，末尾附一条准确原文链接。回复必须绑定本轮一个有效来源；链接缺失、来源过期、重复事件或无可用新内容时不发送，不改成“下午好”等问候。模型仍可因话题不适合当前群而选择沉默。本群 7 天内已分享的同一来源事件避免重复，不影响其他群独立选择。

需要同时开启主动聊天总开关、当前聊天主动开关、允许主动内容联网和本聊天联网搜索。公开关注主题仅用于本机筛选，不把群名、私人账号或聊天原文发送给发布源。官方源暂时不可访问时尝试其他已配置源；源缓存最多 10 分钟，复用时仍重新检查新闻日期。

新模块包含在现有安装器的 bridge/core 目录打包规则中。配置使用 `wechat.proactive.chatSettings[conversationKey] = {mode, topics}`，保留原 `chats` 布尔开关格式及旧客户端保存行为；两种工作模式分别保留设置。

限制：此模式覆盖已配置的官方发布源，并不保证收录科技界所有新闻。发布时间已检查，正文事实仍需模型忠实依据来源；模糊传闻和缺少日期的内容不自动发布。添加功能本身不会自动为所有群开启主动发送。
