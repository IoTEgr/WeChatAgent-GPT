# 长期记忆

记忆 → 长期记忆：按聊天、工作模式管理信息卡、事实与偏好、重要事情和未完成约定。支持修改信息卡、更新同一主题、遗忘、完成约定和单会话停用。停用保留数据，但不再注入或允许模型查询。

数据是可读 JSON：`state/long-term-memory/<账号 SHA256>/<聊天 SHA256>/<工作模式>.json`。账号、聊天、social/assistant 模式互相隔离。不会跨群共享私聊内容，不另存一套原始流水；历史原话仍由现有 SQLite 聊天档案负责，日记仍由鱼的记事本插件负责。

每轮模型输入临时加入最多 2400 字符的记忆资料及固定使用说明，按本轮关键词、未完成约定和最近更新排序，最多 10 条；不把注入块写回 DSH 会话日志。更多信息通过当前聊天限定的 `wechat_memory recall` 查询，每轮工具最多 3 次，不额外调用摘要模型。

模型通过结构化工具决定保存什么：fact（稳定事实、偏好）、note（重要事情）、loop（尚未完成的约定）。自动写入必须带本轮输入中逐字可核验的原话，模型草稿不能当成事实。同一 kind/subject/topic 更新原条目，完全重复不刷新时间，容量满时报错并保留旧内容。每类上限分别为 80/80/40 条。群友 subject 要带昵称及可见标识，避免同名混淆。是否正确理解玩笑仍取决于模型，可在控制台纠正或遗忘。

保存使用原子替换和跨进程排他锁，控制台另有版本冲突检查；损坏文件原样保留、不静默重建。进程异常退出遗留 `.lock` 时需先确认没有进程写入，再移走该锁文件。恢复备份时同样先停止写入。

约定只表示记住一件未完成的事，不会自动创建定时提醒。已有聊天档案可按需检索，不会把所有历史重新分析一遍并编造记忆。模型记忆写入成功不代表回复已经发送，发送仍走原有回执流程。
