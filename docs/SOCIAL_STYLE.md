# 群聊参与和回复表达

首条回复的模拟打字从模型开始生成时计时。生成耗时已经达到原定打字时长时，生成结束后直接发送；生成较快时只补足剩余等待。分条的第二条及后续消息仍分别保留打字间隔。开始时间和发送截止时间随待发送回复落盘，恢复或重试不重新计时。消息合并、群聊冷却和发送配额保持当前聊天设置。

大肥鱼在群聊中默认旁观，只在被点名、问题明确问它、需要关心或确有有趣且相关的补充时回应。普通群友互相聊天通常保持沉默。

交流对象先看真实提及、引用关系和前后发言人；第三人称提到角色名字不算直接唤醒。文字唤醒词只在句首明确称呼时触发，不再按正文任意位置包含名字触发；已有明确 @ 对象时，不因正文另一个名字改变对象。群友之间的“你”和问号不自动指向机器人，机器人刚插过话也不自动接管后续对话。每批附带同一聊天五分钟内最多四条先前群友发言作为对象判断线索，单条最多180字符，只作背景、不逐条补答，不增加额外模型判断请求。对象不清时倾向沉默，明确叫到且仍需回应时正常接话。

决定回应后默认文字，用少量微信黄脸或颜文字传递语气，表情包用于情绪、接梗和斗图。认真沟通、问题讨论、解释误会和复杂说明优先清楚文字；私聊的故事、心情、安慰等声音明显有帮助且方便收听时可选语音，群聊尤其克制。早安晚安通常简短文字，所有形式按内容、关系和对方习惯选择，不设置固定比例或轮换顺序。

普通闲聊等文字回复尽量随后配一张贴合语境的表情包，优先本地表情库，再看微信合集和共享池。文字与图片独立成气泡，不另堆同义文字或表情装饰。严肃讨论、敏感话题、对方只要文字、无合适素材或该聊天关闭表情时保留纯文字。单图、语音仍按语境选择；配图偏好不增加参与频率，也不在发送后另起模型请求追补图片。

普通文字不再自动触发语音复核。只有当前消息明确要求语音而首次仍选择文字时，桥接最多复核一次表达形式；请求文字、链接、代码和独立反应表情保持原形式。复核失败或返回沉默仍保留有效原稿，真正收到安静指令时仍取消投递。

大肥鱼的普通文字黄脸在发送前转换为微信原生短码，如 😂 → [破涕为笑]、🥲 → [苦涩]、😏 → [坏笑]、😅 → [尴尬]。代码、引用示例中的原符号、非黄脸 emoji 和颜文字保留。微信是否呈现图形以当前客户端对原生短码的支持为准。

群里直接说“闭嘴”“先别说话”“别插嘴”“安静一下”等会暂停该聊天。转发记录和“他说让我闭嘴”这类讨论内容不会触发暂停。收到暂停要求时不发确认消息。普通后续消息只留作上下文，主动聊天也暂停；再次点名、@、引用本账号消息或拍一拍可恢复。暂停状态保存在消息缓冲文件旁的 `.participation.json`，按会话及当前账号 self ID 隔离，重启后保留。

模型还在生成的回复会被取消投递；语音发送器在合成后及提交前重新检查暂停状态。已提交给微信的消息无法撤回，不重复提交。

新发记录带有 voice / text / sticker 形式标签，实际语音转录继续按真实回执记录。语音仍由 GPT-Live 根据人格、摘要及相关聊天自行作答，表达形式复核不会把文字草稿当成朗读台词。

语音仅在明确生成失败且未提交微信时重新选择非语音表达；保留原输入及上下文，重新获取当前可用表情候选。该轮只限制语音，不限制自然文字、微信黄脸或颜文字，也不发送故障模板。临时限制随该轮完成清除，后续新消息仍可自主选择语音。
# 群聊 @ 回复

群聊默认直接接话，不自动 @ 最后一位发言人。@ 用于邀请特定的人回答、帮忙、处理事情或注意重要消息，以及多人聊天中确实需要消除对象歧义的场景。普通闲聊、接梗、赞同反对和发表感想通常不 @；熟人调侃偶尔点名，不公开点名不熟悉的人，不频繁 @ 同一人，也不因对方未回应而重复催促。

需要提醒时由模型显式选择本轮 `AT:M编号`，第一条文字气泡才会添加真实提及。后端只接受当前群、近一小时内真实入站消息的关联编号，不能传任意账号、跨群或 @所有人。只是接旧话时，有引用能力才按需引用，否则自然接话或带称呼，不把 @ 当成引用的固定替代。私聊、纯表情包、纯语音、主动分享不强加提及。旧请求缓存会随表达规则版本更新失效，旧的 `autoMention` 参数也不会触发自动提及。

发送复用文字消息的持久化防重和数据库服务器编号回执。回执能证明消息送达，原生提醒效果仍需收件端验收；未验收的构建不自动启用。组件无消息观察器或输入模拟，引用回复保持停用。运行 `scripts/build-mentions.ps1` 编译独立组件。

`TextMessageSendSource.at_user_list` 必须传原始微信账号列表，微信会自行构造 `msgsource/atuserlist`。传入整段 XML 会被转义嵌进列表，文字虽有服务器编号却不会触发真实提醒。该问题已由已发送验收消息的 `source` 字段核实，v2 改传单个真实账号，旧构建的验收状态不能沿用。
